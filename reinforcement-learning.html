Principles of Reinforcement Learning

Atelier thématique · Université Lumière Lyon 2 · 2026

Course material: github.com/pegahani/Atelier-thematique-Principles-of-Reinforcement-Learning

Overview

Reinforcement learning studies how an agent learns to make good decisions by interacting with an environment. In this atelier you learn it by building agents: short theory blocks, then coding in pairs, from planning on a small grid world to deep RL agents that land a spacecraft. There is no exam.

Format: 4 sessions, one of 2h and three of 4h. Sessions 3 and 4 end with a LunarLander leaderboard.

Sessions

#TopicHands-on
1Markov decision processes, Bellman equations, dynamic programmingValue iteration on FrozenLake
2Learning without a model: Monte Carlo, TD learning, SARSA, Q-learningTabular agents
3Deep reinforcement learningDQN from scratch
4Policy gradient methods, PPO, reinforcement learning for language modelsPPO on LunarLander

Learning objectives

  • Model a decision problem as a Markov decision process and solve it by dynamic programming
  • Implement and compare value-based and policy-based algorithms
  • Implement DQN and PPO and make them train reliably
  • Understand how reinforcement learning is used to train large language models (RLHF, GRPO)

Prerequisites

Python and NumPy, basic probability and linear algebra. Some familiarity with PyTorch helps but is not required. Setup instructions are in the course repository.
